## Como instalar

1. **Instale as dependências**

   ```bash
   npm install ogl
   ```

2. **Crie src/components/Galaxy.tsx** Copie o conteúdo de `src/Galaxy.tsx` deste repositório.
3. **Use na página**

   ```tsx
   <Galaxy density={1} hueShift={140} mouseRepulsion />
   ```
